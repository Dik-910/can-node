# can-node 路线图

> 时间窗口：2027-01 → 02。硬约束是装得进日历，不追求做全。

## 阶段拆分

### P0 · 骨架与验证环境
- [ ] STM32 工程初始化（时钟树 / CAN 外设 / 串口日志）
- [ ] 与 `smartgateway` 的 vcan 链路打通（PC 侧桩，先不接真板）
- [ ] Makefile + 单测框架

### P1 · CAN 收发
- [ ] 标准帧 / 扩展帧收发
- [ ] 硬件 ID 过滤器
- [ ] 错误计数读取（TEC / REC，对应内核 `CAN_ERR_CNT`）
- [ ] 总线负载率统计

### P2 · UDS 诊断
- [ ] ISO-TP 分包（单帧 / 首帧 / 连续帧 / 流控）
- [ ] `0x10` 会话控制、`0x3E` 会话保持
- [ ] `0x22` 读数据、`0x2E` 写数据
- [ ] `0x27` 安全访问（种子-密钥）
- [ ] `0x31` 例程控制

### P3 · Bootloader
- [ ] 双区布局规划（Boot + App A / App B）
- [ ] CRC 校验
- [ ] 跳转与回滚
- [ ] 与 UDS `0x31` / `0x36` 传输联调

## 量化指标（简历要用）

每个阶段结束时记录真实数字，不要事后编：
- 升级包大小与耗时
- 单帧收发延迟、总线负载率上限
- 故障注入测试的恢复时间
